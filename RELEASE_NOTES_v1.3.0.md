# Luna Codex v1.3.0 — предварительная версия

Windows EXE содержит окно переключения режимов и встроенный Node.js.
Запустите `Luna-Codex-Setup-v1.3.0.exe`. На новом профиле устанавливается 1.3;
выбор кнопкой сохраняется для новых чатов. Для повторного запуска создаётся
ярлык **Luna Codex** на рабочем столе.

- **1.3 — Fast / Plan / Think:** `gpt-6-luna` с medium для ограниченной работы,
  high для планирования и max для сложного анализа.
- **1.2 — Luna Max:** совместимый рабочий процесс с одним `luna_think` (max).
  Это не откат приложения Codex и не установка исторического релиза 1.2.

Antigravity не устанавливается. Главная модель остаётся выбранной в Codex.
Глобальная инструкция требует делегирования содержательной разработки,
оставляя главному агенту постановку задачи, проверку и окончательное решение.
Вызовы только для чтения отделены от инструментов с правом изменения файлов;
для последних сохраняется штатная проверка разрешений Codex.

Настройки устанавливаются в действующий `CODEX_HOME` или `%USERPROFILE%\.codex`.
Установщик сохраняет посторонние настройки и инструкции, создаёт резервные
копии, допускает повторную установку и защищает пользовательские файлы ролей.
Поддерживаются `--quiet --mode 1.3`, `--quiet --mode 1.2`, `--status`, `--uninstall`.
После переключения перезапустите Codex и откройте новый чат.

Проверены офлайн: фиксированные усилия ролей, запрет редактирования через
инструменты чтения, два параллельных вызова и один писатель, сохранение настроек,
установка/удаление и цикл переключения 1.3 → 1.2 → 1.3. UI-тест вызвал реальные
обработчики обеих кнопок на временном профиле и сохранил скриншот.

Живые вызовы Plan/High и Fast/Medium завершились успешно. Командная строка
процесса Fast подтверждала `gpt-6-luna` и `model_reasoning_effort=medium`.
Независимое подтверждение модели, фактически исполненной сервисом, отсутствует
(`unverified`). Экономия лимитов в процентах не измерялась.

**Ограничение предварительной версии:** строгая инструкция не является
программной гарантией вызова субагента на каждом подходящем запросе.
Предыдущая проверка нового чата выбрала Luna, но не завершилась из-за разрешения
и затем лимита аккаунта. Сквозная автоматическая маршрутизация во всех новых
чатах остаётся непроверенной; эта версия не заявляется как гарантированная.
