# Luna Codex v1.3.1 — Default и новый интерфейс

Окно управления переработано по визуальному референсу десктопного Codex:
светлая боковая панель, белая рабочая область, мягкие карточки режимов и
отметка активного выбора. Это самостоятельное приложение Luna Codex.
Референс: [официальный скриншот OpenAI](https://developers.openai.com/images/blog/long-horizon-4.jpeg).

В окно переключения добавлена третья кнопка **Default — обычный Codex**.
Она удаляет управляемую политику маршрутизации Luna, регистрации MCP и
неизменённые управляемые файлы ролей. Предшествующие настройки агентов
восстанавливаются; главная модель, личные инструкции и остальные подключения
сохраняются.

Выбор Default сохраняется после закрытия окна и перезапуска Codex. Окно
управления остаётся установленным, поэтому можно вернуться к 1.3 или 1.2.
Обновление сохраняет текущий выбранный режим. Режим 1.2 остаётся совместимым
рабочим процессом Luna Max без Antigravity.

Запуск: `Luna-Codex-Setup-v1.3.1.exe` либо установленный ярлык **Luna Codex**.
CLI также поддерживает `--quiet --mode default`.
После переключения перезапустите Codex и откройте новый чат.

Проверены установщик и реальные кнопки окна в цикле 1.3 → 1.2 → Default → 1.3,
сохранение личных настроек, защита изменённых файлов ролей и удаление установки
из режима Default. Проверки выполнялись на временных профилях.

Это предварительная версия. В режимах Luna маршрутизация задаётся строгой
инструкцией и не является безусловной программной гарантией вызова субагента.
