# Примечания к выпуску: Версия v1.2.0

> [!NOTE]
> Кандидат релиза включает описанные ниже изменения Luna bridge, устанавливаемой политики Codex и автономных проверок. `luna_check` и инвентаризация с подготовкой Luna Max завершились успешно. Живая проверка Antigravity не проводилась по просьбе пользователя.

---

## Изменения

### 1. Luna bridge: выполнение авторизованных задач
- `luna_delegate` в режиме `plan` запускает дочерний Codex CLI в песочнице `read-only`; режим `accept-edits` использует `danger-full-access` для файловой системы и команд.
- Вызов включает `--skip-git-repo-check`, чтобы дочерний CLI мог работать в переданном каталоге без Git-репозитория.
- Текст задания для `accept-edits` уточняет, что изменения разрешены только в пределах запроса пользователя; дочернему исполнителю запрещено делегировать дальше или запускать другой Codex CLI/Antigravity.

### 2. Безопасный запуск Codex CLI в Windows
- `.cmd` и `.bat` запускаются через `cmd.exe` с явным экранированием аргументов, вместо `shell: true`.
- Мост отклоняет неподдерживаемые символы в пути batch-файла и аргументах до запуска команды.
- Эта схема используется для проверки версии, статуса входа и делегированных задач.

### 3. Обновлённая политика разработки
- Устанавливаемая политика определяет Codex как координатора, который может самостоятельно исследовать, менять файлы и запускать проверки по просьбе пользователя или при блокировке исполнителя.
- Luna может получать задачи реализации в `accept-edits`; режим `plan` остаётся только для чтения. Политика также требует явно сообщать о прямом переходе к работе и проверять фактические файлы.
- Сохранены требования видимого MCP-вызова для Luna, запрет скрытого запуска исполнителей через shell, запрет рекурсивного делегирования и запрет параллельного редактирования одних файлов несколькими исполнителями.
- Antigravity не вызывается повторно для задачи, если пользователь отключил его или API заблокирован.

### 4. Автономные проверки и документация
- Добавлена проверка `tests/test-luna-bridge-offline.cjs` с подставным CLI: проверяются параметры обоих режимов, non-Git рабочий каталог, флаги запуска и Windows batch-путь; вызов модели не требуется.
- Обновлены policy- и setup-проверки, чтобы сверять новые правила и их сохранение при установке.
- README описывает обновлённый workflow и команды автономных проверок.

## Ограничения проверки кандидата

Автономные проверки не выполняют реальный модельный запрос. Во время подготовки кандидата `luna_check` завершился успешно, как и инвентаризация с подготовкой Luna Max. Живая проверка Antigravity не проводилась по просьбе пользователя.
